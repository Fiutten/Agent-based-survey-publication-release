# Public protocol documentation

This directory contains the rights-safe methodological documentation needed to interpret the released aggregate tables and the manuscript's reproducibility claims.

## Reading order

1. **`search_strategy.md`** — frozen Scopus S1-S8 and Web of Science W1-W4 query logic, filters, counts, deduplication, and cross-database reconciliation. The exact historical Web of Science interface collection label is deliberately left unresolved rather than reconstructed from memory.
2. **`review_governance.md`** — author calibration, final adjudication boundaries, targeted coauthor sign-off, and the boundary between AI assistance and author decisions.
3. **`rif_coverage_check.md`** — purpose, coding semantics, and limits of the post-freeze RIF coverage/applicability check.

## Scope boundary

These protocol files document the executed review and the interpretation of the public release. They do not replace the restricted original database exports or publisher full texts, which are not redistributed.

The primary quantitative denominators remain frozen to the search snapshot closed on **4 August 2026**. Post-freeze records are kept separate and must not be inserted retrospectively into the 3,367 / 463 / 175 / 82 accounting.
